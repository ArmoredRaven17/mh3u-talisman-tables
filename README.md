# MH3U Talisman Tables

Every talisman each of **Monster Hunter 3 Ultimate**'s 17 talisman tables can give, and which tables
can give the talisman you're after.

## How to use it

- Pick a table to see every talisman it can give, or **All tables** for every talisman in the game.
  Each row lists the charms that give it and the tables it can come from.
- Filter by charm, skill, points and slots, or keep only the best rolls.
- The **T1–T17 squares** stay lit for the tables that can roll a talisman matching your filters.
  Set the filters to a few of your own talismans; the table lit every time is your save's table.

## Your save

Open a hunter file (`user1`, `user2` or `user3`, Wii U or 3DS) to see which table it's on. Its
square gets a gold bar. Pick another table to download a changed copy that's on that table, then put
it back in your save folder in place of the original (keep a backup). Only the table changes. The
file is read and changed in your browser and never uploaded.

## How it works

Your table is fixed when you start a save (see the MH3U Cursed Table app for the bug behind it).
The app rolls every charm (Mystery, Shining, Timeworn, Enduring) from every point on every table
with the game's own generator. The skill lists, point ranges, slot odds and talisman names are
read from the game's code. The result was checked against all 258 talismans in a real,
long-played save.
